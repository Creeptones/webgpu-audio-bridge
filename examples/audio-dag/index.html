Audio DAG — a multi-node graph across workers + an AudioWorklet

Apollo Frontier 3 · DAG Stage 2. One connectGraph() call allocates a whole directed acyclic topology; each node mountGraph(handle, { node })s only its incident edges, as the right Role facades, in its own realm. Two oscillators fan into a mixer, which feeds an fx node (a live gain), which broadcasts to both the audio worklet and a meter — every node a separate thread.

osc0,osc1 ─(mpmc fan-in)→ mixer ─(spsc)→ fx ─(spmc broadcast)→ { speaker, meter }   — mixer & fx are intermediate nodes, each on its own Worker, consuming one edge and producing the next. Every edge is wait-free on push, so a slow sink never wedges a source.
