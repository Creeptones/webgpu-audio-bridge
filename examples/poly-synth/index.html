webgpu-audio-bridge — Poly-Synth

Apollo Frontier 7 lifts the JIT's stateless ceiling: a kernel can carry single-sample state (z⁻¹ registers, biquads) and delay-line ring buffers — but a loop-carried recurrence is un-vectorizable along time. Stage 4 re-engages SIMD along the VOICE axis: polyphony gives V = 8 independent voices, each running the SAME stateful kernel with its OWN state + per-voice scalars; pack W = 4 voices per v128 (lane = voice) and one time loop advances all four recurrences lane-parallel. Each voice here is a saw oscillator → a one-pole lowpass (a state register, per-voice cutoff) → a feedback comb (a delay ring, shared decay). Audio starts on the developer's JS fallback; the gate-verified voice-SIMD bytes fade in click-free — and the gate proved every lane bit-exact to an independent scalar voice before they could reach the audio thread.
