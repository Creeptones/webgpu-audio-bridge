webgpu-audio-bridge — Kernel Palette

Apollo Frontier 6 turns the JIT into a language→music engine: a model emits DSP kernels as token streams in a closed kernel grammar, each content-addressed, gate-verified bit-exact, and live-swapped into a running AudioWorklet. There is no model yet — this demo drives the model-free chain with a hand-authored palette. Pick a kernel: a background worker runs the syntax + equivalence gates, getOrCompile caches it by content hash, and the gate-verified WASM SIMD kernel fades in over the JS fallback click-free. Re-pick a kernel and it is a cache hit — the same characterized kernel, no recompile.
