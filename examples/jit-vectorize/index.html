webgpu-audio-bridge — The Autonomous JIT

A developer writes a naive scalar JS DSP kernel — a cubic waveshaper. From the first quantum the AudioWorklet runs it on the JS fallback (audio is immediate). A beat later, connectJit has compiled the SAME function off-thread to WASM SIMD, proven it bit-exact to the scalar source through the equivalence gate, and shipped it into the worklet — which silently upgrades mid-playback with zero audible glitch (the exact-lerp crossfade). The sound never changes; only the per-quantum kernel time drops. 

function softClip(out, x, drive, n) {
  for (let i = 0; i < n; i++) {
    const t = Math.max(Math.min(x[i] * drive, 1), -1);
    out[i] = 1.5 * t - 0.5 * t * t * t;       // cubic saturator — auto-vectorized to f32x4
  }
}
