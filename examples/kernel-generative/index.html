webgpu-audio-bridge — Generative Kernels

Model-free music. A seeded generator walks the Stage-3a constrained-decoder mask (legalNextTokens) to emit random valid kernel-grammar token streams — standing in for the future SLM. Each stream runs the three gates (syntax → equivalence → acoustic) in a background worker; only gate-verified, acoustically-curated kernels reach your ears, morphing into a running AudioWorklet click-free. No model — just the mask + the gates, which are exactly the safety contract the model will plug behind. The source is a built-in arpeggio (in0) + a rhythmic pluck (in1); each kernel shapes them.
