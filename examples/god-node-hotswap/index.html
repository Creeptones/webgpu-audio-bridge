webgpu-audio-bridge — God-Node live hot-swap

Two different-schema patches stream side by side. Patch A is { freq(traj), amp } — a bare carrier. Patch B is { freq(traj), amp, res, detune } — the same pitch motion, plus resonance and detune for a richer timbre. Press Morph to B and the consumer crossfades A→B over ~180 ms on the audio clock with a C² (quintic) click-free seam, while the new res/detune fields ramp in from their defaults — exactly the plan migratePlan(A, B) computes (shown below).

The morph also performs the self-rewriting proof: at button-press the page emits patch B's entire AudioWorklet module from its schema (emitWorkletProcessorModule), Blobs it (toWorkletModuleURL), and addModules it live — a brand-new read path materialized into the audio realm while sound is playing, then shown decoding B's ring in real time.
