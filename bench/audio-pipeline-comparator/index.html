webgpu-audio-bridge — audio pipeline comparator

Renders one reference signal (fundamental + N LFO-modulated harmonic partials) through four GPU-audio pipelines and scores them side by side: A pure-CPU worklet, B GPU → AudioBufferSourceNode (no process()), C GPU block-replace, G hybrid carrier + GPU residual. Each is driven through an identical scripted sequence (settle → freq-change latency sweep → forced GPU-stall continuity → partial-count ramp). The shape to prove: G wins latency, continuity, and spectral richness at once.

The Web Audio side of A / C / G is the render quantum — the spec fixes the default at 128 frames and AudioWorkletProcessor.process() is the per-quantum real-time callback. Path B deliberately is not a process() callback, which is exactly why its latency + continuity story is worse; the bench makes that structural difference quantitative.
